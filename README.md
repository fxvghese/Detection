# IoT-Based Gas Leak Early-Warning System

An ESP32-based gas leak monitoring prototype for air conditioning and refrigeration systems.

The system monitors gas levels, temperature, and humidity, providing local alerts through LEDs, a buzzer, and an OLED display. Sensor readings are uploaded to Firebase Realtime Database for remote monitoring through a web dashboard.

**Technologies:** ESP32, MQ-135, DHT22, OLED, FreeRTOS, Firebase Realtime Database, HTML, CSS, JavaScript.
